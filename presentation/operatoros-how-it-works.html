OperatorOS

Pause, point, ask, and understand the machine.

A video-first multimodal assistant for learning manufacturing equipment before hands-on training.

Product Overview

OperatorOS turns a machine video into an interactive learning workspace.

What the learner can do

  • Upload a local MP4 or ingest a YouTube video.
  • Pause at the exact machine part they care about.
  • Draw boxes, circles, arrows, pen marks, or text.
  • Attach PDF manuals and ask plain-language questions.

What OperatorOS returns

  • A chat answer grounded in the visible frame first.
  • Visual marks that explain the answer on the video.
  • Optional SAM3 tracking when a part should be followed.
  • A highlighted tracking clip from the paused moment onward.
The key idea: a learner can point at something in a real tutorial video and ask, "What is this?"
End-To-End Flow

The full system flow in one clean path.

1

User input

Video, PDF manual, paused timestamp, query, and user-drawn annotation.

2

System preparation

Store video, transcribe with Whisper, capture current frame, and store PDF originals.

3

VLM context

Package the frame, annotation JSON, transcript window, PDFs, and conversation memory.

4

VLM output

Return structured JSON: answer, visual annotations, tracking prompt, tracking annotations.

5

Answer or track

Show the answer immediately. Start SAM3 if tracking is requested or suggested.

VLM Reasoning

What the vision-language model receives and returns.

Frame
The browser captures the exact paused video frame.
Annotations
User drawings are sent as normalized 0-1000 JSON coordinates, with an optional annotated image.
Transcript
Only the nearby transcript window is sent, not the full video transcript.
Manuals
Selected original PDF manuals are attached directly to the OpenRouter request.
Memory
Recent conversation turns keep follow-up questions understandable.
Structured response

The VLM must answer in JSON

  • answer - the chat response
  • annotations - visual explanation marks
  • tracking_prompt - text target for SAM3
  • tracking_annotations - optional box or shape target
SAM3 Branch

SAM3 starts only when tracking makes sense.

Normal answer path The user gets a text answer and model-generated visual marks over the paused frame.
No tracking needed The flow ends here when the question only needs explanation.
Start
SAM3?
Tracking starts if The user says track, follow, trace, or monitor; auto-tracking is enabled; or the VLM returns a tracking target.
Target priority Use VLM tracking annotation first, then VLM tracking prompt, then the user's tracking question.
Tracking Output

SAM3 produces a new highlighted video clip.

1. Clip

Start at the paused timestamp

The SAM3 service clips the source video from the exact source time where the user asked for tracking.

2. Segment

Track frame by frame

SAM3 uses a box prompt when one exists, or a text prompt when the target is only described.

3. Render

Bake masks into video

The mask is blended into each processed frame, then FFmpeg writes a browser-playable H.264 MP4.

Current behavior: the frontend switches the player to the generated tracking clip. Clip time 0:00 maps back to the original paused timestamp.
Architecture

The app is split into services with clear responsibilities.

Frontend

Video player, drawing tools, chat, document selection, transcript panel, and tracking status.

Orchestrator

Central FastAPI gateway. Routes chat, media, transcript, document, and tracking requests.

Video service

Handles MP4 uploads, YouTube ingestion, validation, Whisper transcription, frame indexing, and streaming.

RAGVLM service

Stores original PDFs, builds prompts, attaches selected PDFs, and streams OpenRouter VLM output.

SAM3 service

Loads SAM3, clips video, runs box or text prompted tracking, renders masks, and outputs MP4.

Presenter Summary

OperatorOS is strongest when the demo shows the core loop.

Demo story

  • Load a machine tutorial.
  • Pause when a part is visible.
  • Draw on the part.
  • Ask what it is or what it does.
  • Show the chat answer and visual overlay.
  • Ask to track the part if it should be followed.

One-sentence explanation

OperatorOS gathers everything relevant about a paused moment in a machine video and asks an AI that can explain in words, draw on the frame, and optionally track the selected part forward.

OperatorOS is a learning aid for preparation and explanation. Safety-critical machine operation still requires qualified human supervision.
